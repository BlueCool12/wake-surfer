# Read Cursor owner decisions

이 파일은 owner의 짧은 진입점이다. 현재 결정은
[Domain Owner 결정](./design/08-domain-owner-decisions.md), 구현별 수용 기준은
[Acceptance criteria](./design/09-acceptance-and-non-goals.md)에서 확인한다.

현재 상태는 **Accepted — Ready for implementation planning**이며, 결정일은 2026-07-15다.

consumer는 이 문서 대신 향후 생성될 `docs/realtime-chat/public-docs/read-cursor/`만 읽는다. 현재는 구현과
공개 계약이 없으므로 consumer route도 없다.
